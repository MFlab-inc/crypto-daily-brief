# 暗号通貨市況レポート：自動納品設定台帳

> **目的**：定期タスク、日次スキル、共有ルール、配信パッケージ、添付処理が同一の品質契約に従っていることを、設定変更ごとに検証可能にする。
>
> **運用原則**：この台帳に記録された有効化条件を満たさない限り、完成版4点の自動納品を行わない。本文・数値・画像の品質要件は、常に `暗号通貨市況レポート_統合運用基準.md` を最優先とする。

## 1. 定期タスクの目標設定

| 項目 | 確定値 | 備考 |
|---|---|---|
| タスク表示名 | クリプト前日市況 | 既存の同名スレッドを唯一の起点・納品先とし、名称・スレッドを変更しない。 |
| 実行頻度 | 毎日 | 同一日・同一実行IDの重複を禁止する。 |
| 目標実行時刻 | 既存タスクの時刻を維持（Asia/Tokyo） | 時刻変更は、既存タスクの参照エラー解消後に明示的に検証してから行う。 |
| 実行モード | 同一スレッド継続（`runAsNewTask: false`） | 新規タスク・別スレッド・別チャットへの納品を禁止する。実行ごとの作業ディレクトリだけを分離する。 |
| タスク詳細 | `暗号通貨市況レポート_定期実行プロンプト.md` の全文を参照する | 定期タスク本文に古いテンプレートを複製しない。 |
| 有効化判定 | **保留** | 既存タスクのIDと設定を確認し、重複がないことを確認するまで有効化しない。 |

## 2. 実行前に固定する入力

| 入力 | 必須条件 | 確認方法 |
|---|---|---|
| 対象日 | 実行開始時のAsia/Tokyo日付から暦日で1日引く | `run_context.env` と日次JSONを照合する。 |
| 実行ID | `YYYYMMDDTHHMMSS_JST` | 一意の実行IDを `run_context.env` と作業ディレクトリ名に保存する。 |
| 最優先基準 | `暗号通貨市況レポート_統合運用基準.md` | ハッシュを配信マニフェストの証跡へ記録する。 |
| 品質チェック | `暗号通貨市況レポート_納品前品質チェック.md` | ハッシュを配信マニフェストの証跡へ記録する。 |
| 自動納品契約 | `暗号通貨市況レポート_自動納品契約.md` | マニフェスト作成と添付検証の手順に適用する。 |
| 日次スキル | `crypto-market-report` | `prepare_delivery_package.py` と `validate_delivery_package.py` を同一版で使用する。 |

## 3. 添付を許可する唯一の経路

完成版4点を作成した後、実行タスクは必ず次の順番で処理する。

1. `final_audit_YYYYMMDD.json` が `overall: PASS`、`failed: 0`、必須検査全件PASSであることを確認する。
2. `prepare_delivery_package.py` を実行し、`delivery_permitted: true` の専用パッケージを生成する。作業ディレクトリ外、過去実行、Downloads、更新時刻順、ワイルドカードでの選択は禁止する。
3. `validate_delivery_package.py` にパッケージ、マニフェスト、実行ID、対象日を渡す。
4. 検証器が返す `attachments` 配列の4ファイルだけを、前編、後編、インフォグラフィック、APR実画面の順に添付する。
5. 失敗した場合は完成版4点を添付せず、ブロック理由・取得不能項目・再取得待ちを記した未完了報告へ切り替える。

## 4. フェイルクローズ条件

| 条件 | 自動納品の扱い | 必須記録 |
|---|---|---|
| 既存定期タスクを特定できない | 有効化・新規作成を停止 | タスク参照不能の理由 |
| 同一日・同一実行IDの既存パッケージがある | 追加の完成版4点を作らない | 既存パッケージのマニフェスト |
| 最終監査が不合格、未実施、または成果物より古い | 添付停止 | `final_audit` の結果または不足理由 |
| 成果物のSHA-256が最終監査またはマニフェストと不一致 | 添付停止 | 配信ゲートの失敗記録 |
| パッケージに許可外・旧版・別日ファイルがある | 添付停止 | 添付検証器のエラー |
| APR実画面、取得不能理由、必須の4点のいずれかが欠ける | 完成版4点として納品しない | 未完了報告 |

## 5. 設定変更の受入試験

| 試験ID | 内容 | 合格基準 |
|---|---|---|
| A-01 | 正常な同一実行の4点をパッケージ化する | `prepare_delivery_package.py` がPASSし、4点のみを収録する。 |
| A-02 | 監査後に前編を改変する | 配信ゲートがSHA-256不一致で停止する。 |
| A-03 | パッケージへ前日版の前編を混入する | 添付検証器が許可外ファイルとして停止する。 |
| A-04 | 添付直前にパッケージを再検証する | `attachments` が4ファイルのみ、所定の順序で返る。 |
| A-05 | 定期タスクを更新する | タイムゾーン、既存実行時刻、`runAsNewTask: false`、参照プロンプト、フェイルクローズが実画面またはCLIで照合できる。 |
