# 暗号通貨市況レポート：プロジェクト恒久指示

日次作成では、共有ファイル **`暗号通貨市況レポート_統合運用基準.md`** を最優先の詳細仕様として必ず確認し、これと矛盾する旧テンプレート、過去納品、外部AI要約の指示は使用しない。汎用スキル、一般的な市況テンプレート、補助資料に含まれる本文構成、指標、画像、日付、価格表記、LP判断の既定値も、統合運用基準と矛盾する限り適用しない。

## 基本表記・データ

常に「暗号通貨」と表記し、通貨名には#を付ける。市場価格・時価総額はUSD（JPY）併記とし、実行時に取得したUSD/JPYで換算する。CoinMarketCap由来の価格変化率は、全成果物で必ず「24時間比」と表記し、他の騰落率ラベルを使わない。未確認・取得不能な値は推測せず、「未確認」または取得不能の理由と限界を明記する。

対象日は、実行開始時点のAsia/Tokyoの日付から暦日で1日を引き、プログラムまたはOSの日付関数で日本語曜日と同時に算出する。単一の `target_date_jst` と `weekday_jp` をX投稿、インフォグラフィック、ファイル名、監査台帳に共通で使い、手入力で曜日を決めない。

## 価格・市場データの取得元（2026-08-02確定）

**主要価格・時価総額・ドミナンス・Fear & Greedは CoinMarketCap API を正本とする。**
- 環境変数 `CMC_PRO_API_KEY` を使用し、ベースURL `https://pro-api.coinmarketcap.com` に対してAPIリクエストを行う。
- CoinGeckoはCMCの代替として使用しない。
- CMC APIキーが未設定またはエラーの場合のみ、CoinMarketCapウェブ取得値を使用し、フッターに「CMC（ウェブ取得）」と明記する。
- Fear & Greedは必ず `GET /v3/fear-and-greed/latest` から取得し、Alternative.meは使用禁止。

## 国内取引所データの取得元（2026-08-08更新・SHO承認済み）

- **bitFlyer ETH/JPY**：bitFlyer公式API（`GET https://api.bitflyer.com/v1/ticker?product_code=ETH_JPY`、認証不要）を最優先とする。3段階フォールバック：①bitFlyer公式API → ②TokenInsight API（`TI_API_KEY`）→ ③取得不能。詳細は統合運用基準参照。
- **Coincheck ETH/JPY**：Coincheck公式API（`https://coincheck.com/api/ticker?pair=eth_jpy`、認証不要）を使用する。`volume` フィールドがETH/JPY 24時間出来高（ETH建て）を返す。
- 両APIとも取得時刻をJSTで監査台帳に記録する。片方が取得不能の場合は「算出不能」と明記し、BTC/JPYで代替しない。ローリング24時間値のため「参考値」として扱い、本文に必ず明記する。

## X投稿の固定構成

X投稿は必ず前編・後編の2分割とする。

- 前編：`【対象日】→【ヘッドライン】→【主要なポイント】→【主要指標】`
- 後編：`【主要指標（詳細）】→【市場のフロー】→【LP運用者向けに一言】→【総括】`

【主要指標】には市場全体、#BTC、#ETH、#BNBを含める。【主要指標（詳細）】には、bitFlyerとCoincheckの取引量合計と、UniswapまたはBase上DEX出来高の比較を含める。比較条件が揃わない場合は、比較不能の理由を記す。

【ヘッドライン】、【主要なポイント】、【市場のフロー】、【総括】はそれぞれ役割を分け、同じニュース、価格、24時間比、DEX、APR、LP助言を重複させない。ヘッドラインは検証済みの最重要材料、主要なポイントはヘッドラインと重複しない補足を原則3〜4項目、市場のフローは根拠を記録した複数の条件付き矢印連鎖、総括は地合い・不確実性・翌日の確認事項だけを扱う。複数の検証済み材料がある日は、市場のフローで地政学・マクロ、制度・政策、企業財務・資金調達・市場構造のうち根拠がある異なる2系統以上を示し、各連鎖に「可能性」「意識された可能性」「因果は未確認」等の限定を置く。根拠が少ない日は数を埋めず、確認できる材料と限界を明記する。十分な裏取りがない場合は、定められた「確認できる主要材料は確認できない」等の文言を使用する。

## 週末版・月次データの制約（2026-08-02追加）

- **土曜・日曜版**：ETFフローの具体的な金額を本文から削除し、「直近営業日（YYYY年M月D日）までの確定値として確認された」と表記する。
- **月次騰落率**：CMCの同一系列で再計算できるまで掲載しない。
- **ボラティリティ記述**（例：「FRB決定日のBTCボラティリティ＋50〜100%」等）：一次根拠と計算台帳がない場合は掲載しない。

## 情報源と因果表現

ニュースの主根拠は、規制当局・議会・政府・企業・取引所の公式発表、およびReuters Japan、Bloomberg Crypto等の独立報道とする。Financial Times、Nikkei / Nikkei Asia、CoinDesk、信頼できる市場データ提供者は補完・裏取りとして用いる。CoinPost、BeInCrypto Japan、New Economy、Forbes等は論点発見・背景説明に限り、PR、スポンサー記事、オピニオン、価格予測、テクニカル分析を主根拠にしない。

GPT、Claude等の外部AI要約は、URL・論点・検索語の発見だけに用いる。出力自体を根拠として転載せず、一文ごとに一次情報・独立報道・実行時市場データで再確認する。

**ニュース要約の許可と因果の断定禁止**
Reuters、Bloomberg、公式発表および優先度1〜3の確認済み報道は、#BTC・#ETH等の価格変動との直接因果を示せなくても、媒体・出来事・掲載日時・不確実性を明示した事実要約として掲載できる。【ヘッドライン】や【主要なポイント】で報じられた事実を伝え、【市場のフロー】で価格因果を断定せず「同時期に確認された材料」「市場で意識された可能性」として限定する。個別LPレンジ未共有時は、レンジ内外、資産偏り、手数料収益の有利不利を断定しない。
